# Font yang di-host sendiri

Keduanya berlisensi **SIL Open Font License 1.1**, jadi bebas dipakai dan
didistribusikan ulang selama berkas lisensinya ikut disertakan.

| Berkas | Font | Dipakai untuk |
|---|---|---|
| `plus-jakarta-sans-latin.woff2` (27 KB) | Plus Jakarta Sans, variabel 400–800 | seluruh teks halaman |
| `caveat-latin.woff2` (74 KB) | Caveat, variabel 400–700 | tulisan tangan pada note & aksen |

Di-host sendiri (bukan lewat Google Fonts) supaya halaman tidak memanggil server
pihak ketiga sama sekali.

Teks lisensi Plus Jakarta Sans ada di `OFL-PlusJakartaSans.txt`. Lisensi Caveat sama
persis isinya, dengan pemegang hak cipta Impallari Type.
